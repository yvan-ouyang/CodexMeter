- Powertools 的 `quota-samples.json` 只存部分已消耗窗口、阈值变化检查点，`lastAt` 不是每个 checkpoint 的数值采集时间；无法提供所有有效/未知/100%/重置窗口的一致完整当前快照。**不读取该文件的实际内容，不当额度源。** 完整桌面额度导出暂无已验证契约。CLI 本机已有真实观测但可能因空闲长时间不更新，即使进程仍运行。

## 具体契约

### 供应商下拉布局

- 顶部供应商选择固定在滚动内容上方，Antigravity 启用且显示在下拉时排第一且每次打开重新选中；不可见时回落到 Codex。Codex 永远可访问，Go 仅按原有启用且显示偏好出现。关闭当前供应商显示时回落到当前合法默认，不保存失效选项。只有一个供应商时不额外渲染 Tab。可见性只由设置决定，不因额度缺失、读取失败或统计尚未启用而隐藏页。默认重选发生在真实弹窗从关闭到打开的边界（包括被系统自动关闭后再打开）；期间设置重建、刷新完成或其他供应商启用不能抢走仍合法的选中页。Tab 切换、隐藏测量副本及 SwiftUI 重绘均不触发供应商请求、文件读取或其他副作用。
- 顶部账号/计划、加载状态与错误归属于当前页面，不把 Codex 账户/失败提示挂到 Antigravity，不把 CLI 观测账号当作下方桌面记录的归属。刷新/设置/退出等底部操作持续可见，保持原全局刷新动作，滚动测量/定位/缩放/无障碍仍正常；切换后的内容不应被旧页滚动位置、尺寸或悬浮提示遮住。
- Antigravity 首屏复用现有四桶额度卡（继续遵循原模型配额组偏好；选全部时展示源实际提供的组及窗口，缺失不补额度），随后紧凑统计。额度与本机用量源互相独立，即使其中一个缺失或失败另一个仍展示。今日/近7天/本月切换按本地日历；「保留记录」明确非生命周期合计。短期趋势与模型细分可收起；完整统计在设置页查看，不把庞大的 Powertools 看板塞进 380px 下拉窗。
- Powertools 本机统计是 Antigravity 设置内一个独立、默认关闭的只读 opt-in，不是第三种额度来源。总开关关闭停止两个本地来源的展示和读取而保留偏好；重新启用时只恢复显式选定的能力。额度来源在旧路径和 CLI 之间切换不自动开关用量统计；既有额度源、模型组、菜单栏/下拉显示偏好继续原义（模型组用于额度，不筛掉已记录用量）。下拉隐藏只影响展示，不取消已经启用的来源。设置页与下拉消费同一个应用级发布状态，不各自解析文件；新统计开关/独立发布不触发旧额度客户端、Codex 自动化与通知、写共享快照或 Widget 重载。

### 已有本地数值的白名单与时间、去重

- 仅在用户选择 Powertools 本机用量后，读取固定桌面目录 `~/.gemini/antigravity/plugin_data/agy-powertools/usage-history-cache.json` 和同目录 `pricing.json`。无目录遍历、环境变量覆盖、子进程、权限提升、源文件写入；拒绝非普通文件或越界链接（包括父目录跳出允许根）。限制 usage 16 MiB、25,000 条、price 2 MiB、合理模型/ID/费率长度与数值上下界；限制实际读入字节，超限不以截断字节冒充合法快照。每次捕获完整的单份文件，后台 utility 执行 I/O 和 JSON 解析，不能因慢磁盘/网络阻塞 UI。一份聚合仅使用同次检查捕获的缓存/单价，不要求两个外部文件具备事务一致性；遇到并发写入导致的无效 JSON 按该源读取失败处理，下次允许的检查恢复，不无限等待。价格读取失败/缺失不使已成功取得的 Token 消失。不上传、不写原始记录或新增完整账本；日志/错误仅报告检查状态、有限汇总计数等脱敏信息，不打印记录、ID、身份或忽略字段。
- 使用结构化解码只取 `id`,`timestampMs`,`model`,`inputTokens`,`cacheReadTokens`,`outputTokens`，可读取少量合法展示枚举而不记录正文。ID 只在聚合内存中用于去重，不持久化。时间必须是有限合法 Unix 毫秒数，保留小数精度转换，不以读入时间替代；不能定位实际已发生日期的事件不纳入任何汇总并标不完整。Token 严格 JSON 数值、非 Bool、非负整数值且累计不溢出；0 为真实零，缺失/坏字段使该行不可计并标部分。逐行校验，单条坏字段不使可独立验证的其他行丢失。对于相同非空有效 ID，按时间、模型计量归属及三个 Token 桶比较；相同计量事实仅计一次（不比较或保存错误正文等无关字段）；无法证明相同的重复组/已知冲突 ID 整组剔除并明确不完整，不能随遍历顺序选值。模型缺失/未知仍保留其他合格 Token 与记录数，价格未知。仅规范化已知呈现的大小写、空格、Claude 数字版点号及明确推理档位后缀；不得将不明确的 Orchestrator 或未知模型猜成某已知模型。只认指定桌面缓存内的记录，统一标为「本机桌面记录（不按账号归属）」；不借用 CLI 账号，不与 CLI 历史缓存相加，不声称全账户覆盖。
- 记录数为可验证的去重缓存事件数（并非实际计费请求保证）；总输入=未缓存输入+缓存输入，总Token=总输入+输出，缓存命中率=缓存输入/总输入（无输入未知，不平均百分比）。输出已包含 thinking，不再加。汇总使用同一基准时钟和本地日历/时区：今日从当天零时起，近7个日历日含今天及前6天，本月从本月首日零时起，均只计已发生事件；保留记录只计本份缓存合格记录，不再根据读取时钟人为裁出一个生命周期。跨本地午夜/月界/时区变化不能把上一时段总数冒充新「今日」；下次允许的检查重新聚合，在此之前可依据已读数据纯本地重算或明确标注原汇总日期/时点，不由此增加后台文件 I/O。时间区间无记录不声称已完整观察到0；明确「当前记录无该时段数据」，趋势无记录日也不当作确认零消耗。合法空列表、有效行均为零与全部/部分行不可验证须区分。
- 显示记录最早/最新时间、读取/文件更新时间、约90天/2万条的插件保留策略及本份记录实际覆盖范围。成功重读不会更新文件 mtime 或最新事件时间；长期未改动可能是空闲或插件尚未更新，提示可能滞后，历史仍可显示（它不是已发生消耗越过某固定时间就失效）。损坏/权限/版本不符或超限时明确本轮不可读；不得把上次结果伪装成本轮成功，不能虚构空账单或从 Codex/额度兜底。恢复后替换为新一份合格汇总；不跨次累加。

### API 等效计价

- 使用同目录 Powertools 已缓存的公开价格，`rates[].model/input/cache/output` 每百万Token USD；`until`（合法 UTC 日历日期）与 `next`（完整合法三桶费率）同时有效时，事件 UTC 日期严格早于 `until` 用原价，到达及以后用 `next`；变价字段缺一或不合法时该价项不可靠，不任意选半套费率。没有变价字段才按单一价项计算。日历统计本地时区和价格生效 UTC 日期是两个独立口径。价格目录 `checkedAt` 可选且有效则展示；不得把重读时间当作价格验证时间。只接受完整合法价格项、精确匹配规范化模型；未知/冲突价格不猜测。不主动访问目录字符串中的 URL 或供应商，不引入插件内置价/联网回退；价格缺失或损坏时 Token 照常显示。已有价格仅表示插件给出的公开列表价参考，不独立宣称实时官方核价，不承诺追溯插件未保留的过往价目；价格文件变化后，仅在仍保留有效变价日的范围内按事件日区分历史价格。使用十进制或可靠有限非负算术按 **(新输入×input + 缓存输入×cache + 输出×output)/1e6** 计算；各记录在自身模型与日期定价后求和，未知行不按0。显示「已计价记录 / 记录数」与未计价说明；无有效价格显示 `—`，部分已计金额明确为部分；有效零价或零 Token 可以为0。所有时段、模型和趋势使用一致的口径；汇总后展示金额，不把未知或很小的非零费用伪称免费。已记录三桶无法证明缓存创建/存储/其他项目：统一说明估算不包含未记录计费项，不表示实际订阅扣费。只读取已提供的定价表，不扩展原 OpenAI 价格引擎。

### 五分钟读刷新与额度语义

- CLI quota 和 Powertools 本机统计都只读。全局设置为任意自动档（30秒、1分钟、5分钟）时，已启用的本地来源独立于 Codex 网络按固定5分钟检查；手动档不安排后台文件 I/O，但保持启动一次和显式交互读。启动、实际打开下拉/设置（包括复用窗口重新显示）、显式手动刷新、启用/相应源变化立即请求已启用本地来源检查；不要求等待网络完成。保留底部全局刷新对既有供应商的动作，不把 Tab 切换改成刷新；本地检查不应因 Codex 在途刷新被禁用或等待其成功，允许通过共享入口或本地检查动作独立触发而不重复发起 Codex 请求。
- 用应用级唯一发布者合并各本地来源的重叠触发，同一来源同一时刻最多一轮有效读取，不因弹窗/设置显示与隐藏测量或重复通知把一次检查放大为多个；避免反复取消重启导致读不到结果。关闭总开关/统计开关、切换相关额度源、任务停止时使相应在途结果失效，发布前再核对当前开关、来源和代次。切换自动/手动档及时取消定时后续读取，不累积休眠期间的历史轮次；唤醒后按当前时间进行陈旧判断，自动档按其正常节奏检查，手动档不因此补定时读取。全局 Codex 刷新频率、已有本机成本读取、重置卡补读、旧 Antigravity 路径原样。价格与统计源读失败独立降级；两个本地来源之间也不互相阻断。
- CLI 快照 `capturedAt` 仍是回调观测时刻；最近本地检查为单独状态，只有实际完成读取才更新（包括等待/失败的检查结果，不把失败称同步成功），时间不从 Codex 刷新或 UI 重绘借用。到达/超过5分钟、未来或非法时间标记可能过期，按真正捕获时间计算，过期或已达重置边界保留最后比例但不显示伪重置、倒计时/继续推算。该 CLI 专属阈值替换旧 120 秒阈值，所有 CLI 展示面（含自定义菜单栏项目及无障碍）一致；未知/禁用/缺失桶、等待态、损坏文件、单份快照和切源行为承接既有 CLI PRD，不拼旧比例或旧身份。年龄标记及跨重置边界的纯显示变化在手动档也按时钟更新，不读取供应商。设置与下拉说明「自动档每5分钟检查本地文件，手动档仅启动/交互读；真正额度由CLI状态产生；桌面独立使用/CLI空闲时可能未更新，正常使用 `/usage` 可促发」。不从 Powertools 的不完整 quota checkpoints 回填或混合官方额度。菜单栏沿用现有来源标识和布局。

## 待验收与风险

- **Assumption（非阻断）**：实际本机 Powertools 文件已由用户授权的数值探针确认可读且现有价目录可计价，但社区 schema、文件写入时间及保留策略无供应商稳定保证，超限、版本变化、价格目录不全应安全降级。无法证明插件始终收集、完整账户历史、桌面与 CLI 同账号或空闲 CLI 的实时额度更新；上述来源边界已确认，既不读取其他文件验证，也不自动补源。
- **验收影响（详细矩阵下一阶段设计）**：用合成固定记录验证时间/去重/价格及其不完整状态、按本地日历与 UTC 变价日的独立边界、两源有界只读/独立失败与恢复、五分钟及手动模式（不用真实等待即可验证调度和晚到结果）、打开与设置重建的区别，以及既有 Codex/Go/旧源通知/Widget/菜单栏保护。仅有 CLI 陈旧阈值和本地检查时序测试的预期按本次契约改变。真实本机对照必须是同一桌面缓存代次、同一时段、去重/缺失处理和按日期适用价模式的统计，而非直接比较可能合并 CLI/live 数据、采用其他价格模式的 Powertools 总看板。真实个人数据不作为 fixture、提交、日志或评审附件，不要求额外模型消息或改变现有插件。
- **发布/撤回边界**：后续才进行已授权 fork 测试分支的完整 Xcode 测试、Intel 产物架构/最低系统/签名与本机安装和真实 GUI 验收；旧构建或本地 Foundation 核心测试不能替代。新统计不改变外部缓存、CLI 回调配置或共享快照 schema，只新增本机启用偏好及内存展示状态；关闭该统计或回退原兼容测试包不需要回写/迁移 Powertools、CLI 缓存，不改变 Bundle ID 或正式发布渠道。若必须取得其他持久化来源、引入新共享契约或扩大自动采集权限才能实现目标，停止并另行确认范围。

独立挑战结论：现有证据足以补齐本次设计契约；无剩余高影响用户决策或 blocking 项。收口仅澄清已选择方案的状态、数据与边界，不改变 Scope Contract 和已确认方案图；不重复要求确认同一决策。
